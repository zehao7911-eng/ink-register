# Ink Register

Register each transparent film against the paper and pull a print. Six editions introduce translation, rotation and three-ink overlays. Drag to shift the film, use the arrow buttons for fine steps, and turn with the curved arrows. Arrow keys and Q/E also work. Guide shows the target imprint and the remaining offset.

Open index.html or standalone.html. Both contain the complete game. The archive stores completed editions on this browser. Run `node core-tests.mjs` for the controller and SDK mock checks.

Gameplay reference. Combos Align 100 by Vexxxxx. The first frame was played from a crooked state through 97% to 100% PERFECT. Ink Register uses original poster illustrations, a layered press, an archive and sequential ink passes.

## GameWave

Import the ZIP with index.html at the archive root. The game boots in an ordinary browser and detects optional window.neonlib methods independently. The first accepted adjustment or print begins a session. A finished edition or an explicit restart of a started session ends it. A restored in-progress plate waits for an accepted action.

The `ink-register-v1` browser save contains the active plate and collection. GameWave cloud saves contain the Ink Register profile envelope with completed editions and one-time reward flags. Unknown or failed cloud loads leave the local progress available. A confirmed current-player like unlocks brass rails, and a direct comment unlocks roller confetti. Three and six finished editions unlock the same perks through play. Registrations and rewards were tested with mocks. Actual GameWave App import and account callbacks require testing in the supported host.
